### <span id="route_plan">路线计划</span>：

### **第一天：桂林市区游览**
> 象鼻山 → 两江四湖 → 正阳步行街、东西巷 → 日月双塔 → 返回酒店

+ **象鼻山**
    - 游览时间：约1小时
    - 桂林市城徽，象山水月奇观
+ **两江四湖**
    - 桂林市区标志性景点
    - 可乘船游览或步行观赏
+ **正阳步行街、东西巷**
    - 美食街，品尝当地特色小吃
    - 购物、休闲好去处
+ **日月双塔**
    - ⭐ **夜晚开灯更美**，建议晚上前往
    - 日塔和月塔交相辉映

### **第二天：海洋乡大塘边村 → 阳朔县城**
> 休息到中午 → 自驾到海洋乡大塘边村拍银杏 → 傍晚直接去阳朔 → 入住嵩嵩民宿

+ **海洋乡大塘边村**
    - 📍地点：灵川县海洋乡大塘边村
    - 🍂11月是观赏银杏的最佳季节
    - 📸摄影打卡地，金黄色的银杏叶美不胜收
    - ⏱️游览时间：约2-3小时
    - 💰门票价格：约¥20-30/人（部分区域可能免费）
+ **阳朔县城**
    - 傍晚自驾前往阳朔
    - 入住**嵩嵩民宿**
    - 晚上可自由活动，适应阳朔环境

### **第三天：遇龙河 → 十里画廊 → 阳朔西街**
> 上午遇龙河竹筏 → 下午骑行十里画廊 → 晚上逛阳朔西街

+ **遇龙河竹筏**
    - 上午前往，乘坐人工过坝竹筏
    - ⏱️游览时间：约40-90分钟（根据路线不同）
    - 体验原生态的漓江风光
    - 💰门票价格：约¥160-255/人（根据路线不同）
+ **十里画廊骑行**
    - 下午骑行游览
    - 💰租电瓶车：¥30/辆
    - ⏱️骑行时间：1～2小时
    - 🚴骑行路线：
        * 十里画廊
        * 工农桥
        * 遇龙河步道
        * 水坝-凉亭
        * 沿途风景如画
+ **阳朔西街**
    - 晚上自由漫步
    - 品尝美食、购物、体验当地文化

### **第四天：富里桥 → 千里江山图 → 返回永州**
> 富里桥拍照 → 千里江山图打卡地 → 返回永州

+ **富里桥**
    - 📍地点：阳朔县白沙镇遇龙河上游
    - 📸拍照打卡地，古桥与山水完美结合
    - ⏱️游览时间：约1小时
    - 🌉明代古桥，遇龙河上最古老的石桥
    - 💰门票价格：免费（部分区域可能收费）
+ **千里江山图**
    - 📍地点：阳朔县
    - 🎨大型实景山水画卷打卡地
    - ⏱️游览时间：约1-2小时
    - 🖼️体验中国传统山水画的意境
    - 💰门票价格：约¥80-120/人
+ **返程**
    - 下午/晚上返回永州

#### <span id="scenic_area">景区景点详情</span>：

**象鼻山**
+ 桂林市城徽，因山形酷似一头巨象而得名
+ 游览时间：约1小时
+ 最佳拍照点：象鼻山前

**两江四湖**
+ 两江：漓江、桃花江
+ 四湖：木龙湖、桂湖、榕湖、杉湖
+ 可乘船夜游，欣赏灯光秀

**日月双塔**
+ ⭐ **建议晚上前往**，灯光开启后更美
+ 日塔为铜塔，月塔为琉璃塔
+ 两塔交相辉映，夜景迷人

**海洋乡大塘边村**
+ 灵川县海洋乡著名银杏观赏地
+ 11月是观赏银杏的最佳季节
+ 金黄色的银杏叶铺满大地，美不胜收
+ 摄影爱好者必打卡地
+ 建议上午或中午前往，光线较好

**遇龙河**
+ 人工竹筏，体验原生态漓江风光
+ 过坝体验刺激有趣
+ 可选择不同路线的竹筏游览

**十里画廊**
+ 阳朔最美骑行路线
+ 沿途风景如画
+ 可随时停车拍照

**富里桥**
+ 位于遇龙河上游，明代古桥
+ 遇龙河上最古老的石桥
+ 古桥与山水完美结合，拍照打卡地
+ 建议上午前往，光线较好

**千里江山图**
+ 大型实景山水画卷
+ 展现中国传统山水画的意境
+ 结合现代科技与传统文化
+ 体验独特的视觉艺术享受

**阳朔西街**
+ 阳朔最著名的商业街
+ 集美食、购物、娱乐于一体
+ 晚上热闹非凡，体验当地夜生活
