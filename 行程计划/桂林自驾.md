### <span id="route_plan">路线计划</span>：

### **第一天：桂林市区游览**
> 象鼻山 → 两江四湖 → 靖江王城 → 日月双塔 → 正阳步行街、东西巷 → 返回酒店

+ **象鼻山**
    - 游览时间：约1小时
    - 桂林市城徽，象山水月奇观
+ **两江四湖**
    - 桂林市区标志性景点
    - 可乘船游览或步行观赏
+ **靖江王城**
    - 明代藩王府，历史文化景点
+ **日月双塔**
    - ⭐ **夜晚开灯更美**，建议晚上前往
    - 日塔和月塔交相辉映
+ **正阳步行街、东西巷**
    - 美食街，品尝当地特色小吃
    - 购物、休闲好去处

### **第二天：兴坪古镇 → 阳朔县城**
> 出发兴坪古镇 → 兴坪码头游漓江 → 驾车到阳朔县城 → 入住西街附近 → 晚上观看实景演出

+ **兴坪古镇**
    - 千年古镇，漓江边的小镇
+ **兴坪码头游漓江**
    - 📍地点：兴坪码头
    - ⏰售票时间：8:00-16:30
    - 📏里程：7km
    - ⏱️游览时间：70-90分钟
    - 🛥️全程路线：兴坪渔村游（往返）
    - 💰门票价格：
        * 普通船：¥85/人/次
        * 三星船：¥115/人/次
        * 动力竹筏（4人坐）：¥120/人
+ **阳朔县城**
    - 入住西街附近酒店
    - 晚上观看实景演出：
        * **印象刘三姐**（大型山水实景演出）
        * **桂林千古情**（备选）

### **第三天：遇龙河 → 银子岩 → 十里画廊**
> 遇龙河（备选富里桥）→ 银子岩 → 十里画廊骑行 → 西街漫步 → 西街

+ **遇龙河**
    - 备选：富里桥
    - 乘坐人工过坝竹筏
    - 往返时间：约40分钟
    - 体验原生态的漓江风光
+ **银子岩景区**
    - ⏰游览时间：约1小时
    - 桂林溶洞奇观
    - 中午抵达
+ **十里画廊骑行**
    - 💰租电瓶车：¥30/辆
    - ⏱️骑行时间：1～2小时
    - 🚴骑行路线：
        * 十里画廊
        * 工农桥
        * 遇龙河步道
        * 水坝-凉亭
        * 沿途风景如画
+ **西街**
    - 晚上自由漫步
    - 品尝美食、购物、体验当地文化

### **第四天：相公山 → 千里江山图 → 返回永州**
> 相公山观日出 → 千里江山图 → 返回永州

+ **相公山**
    - 📍地点：阳朔县兴坪镇
    - ⏰最佳游览时间：日出时分（建议早上5-6点出发）
    - 🏔️海拔：约200米
    - ⏱️游览时间：约1-2小时
    - 🌅观景台俯瞰漓江第一湾
    - 📸摄影爱好者必打卡地
    - 💰门票价格：约¥60/人
+ **千里江山图**
    - 📍地点：阳朔县
    - 🎨大型实景山水画卷
    - ⏱️游览时间：约1-2小时
    - 🖼️体验中国传统山水画的意境
    - 💰门票价格：约¥80-120/人
+ **返程**
    - 晚上返回永州

#### <span id="scenic_area">景区景点详情</span>：

**象鼻山**
+ 桂林市城徽，因山形酷似一头巨象而得名
+ 游览时间：约1小时
+ 最佳拍照点：象鼻山前

**两江四湖**
+ 两江：漓江、桃花江
+ 四湖：木龙湖、桂湖、榕湖、杉湖
+ 可乘船夜游，欣赏灯光秀

**靖江王城**
+ 明代靖江王的府邸
+ 历史文化底蕴深厚
+ 可了解桂林历史文化

**日月双塔**
+ ⭐ **建议晚上前往**，灯光开启后更美
+ 日塔为铜塔，月塔为琉璃塔
+ 两塔交相辉映，夜景迷人

**兴坪古镇**
+ 漓江边千年古镇
+ 古镇风貌保存完好
+ 可体验当地民俗文化

**漓江精华段（兴坪码头）**
+ 20元人民币背景取景地
+ 漓江最美的一段
+ 可选择游船或竹筏游览

**遇龙河**
+ 人工竹筏，体验原生态漓江风光
+ 富里桥为备选景点
+ 过坝体验刺激有趣

**银子岩**
+ 典型的喀斯特溶洞
+ 钟乳石形态各异
+ 被誉为"世界溶洞奇观"

**十里画廊**
+ 阳朔最美骑行路线
+ 沿途风景如画
+ 可随时停车拍照

**相公山**
+ 阳朔著名观景台
+ 俯瞰漓江第一湾的最佳位置
+ 日出时分景色最美，摄影爱好者必打卡地
+ 建议早上前往，避开人流高峰

**千里江山图**
+ 大型实景山水画卷
+ 展现中国传统山水画的意境
+ 结合现代科技与传统文化
+ 体验独特的视觉艺术享受

**印象刘三姐 / 桂林千古情**
+ 大型山水实景演出
+ 展现桂林山水文化
+ 建议提前预订门票
