### <span id="tips">💡实用贴士</span>

#### 1. 交通与停车
+ **导航**：优先高德实时路况，目的地直接设为“停车场”而非店名
+ **停车策略**：执行“1天1次停车”原则，尽量不在饭点挪车
+ **错峰建议**：11:30前吃完早茶，17:30前进入晚餐餐厅
+ **自驾注意**：老城区巷道窄，路边临停抓拍较多，避免侥幸停车

#### 2. 预约与排队
+ **预约顺序**：先订午晚餐，再安排中间小吃点
+ **排队策略**：首店排队超过45分钟可切换备选店，避免拖垮节奏

#### 3. 用餐与避坑
+ **就餐节奏**：每站吃“半份/分食”，一天可多打卡3-5家
+ **避坑建议**：优先本地人稳定复购店，少选网红首店首日
+ **点单原则**：1道招牌+1道基础款，口味不合适可及时止损

#### 4. 天气与装备
+ **穿着建议**：轻便鞋+透气衣物，全天步行较多
+ **随身物品**：纸巾、湿巾、充电宝、薄外套

### <span id="tips">💡实用贴士</span>

#### 1. 交通与停车
+ **导航**：优先使用高德实时路况，避免高峰拥堵路段
+ **停车**：热门商圈停车位紧张，建议优先选择商场停车场
+ **自驾注意**：老城区道路较窄，留意单行线与非机动车

#### 2. 门票与预约
+ **提前预约**：热门景点和餐厅建议提前1-2天预约
+ **证件准备**：随身携带身份证件，部分景点核验使用

#### 3. 用餐与避坑
+ **就餐时段**：顺德热门餐厅午晚高峰排队较久，错峰更省时
+ **避坑建议**：优先明码标价门店，避免景区门口临时拉客店

#### 4. 穿搭与天气
+ **穿着建议**：以轻便舒适为主，步行较多建议运动鞋
+ **雨天预案**：备轻便雨具，优先室内景点线路
