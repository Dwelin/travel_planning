### <span id="food">🍜美食清单</span>

#### 午餐
+ **黄但记知味食府（顺联广场）**
  - 推荐：陈村粉（牛腩陈村粉、咖喱蟹陈村粉）
  - 亮点：始创于1927年的老字号，陈村粉薄、爽、滑、软
+ **浓汤卜卜贝（陈村农贸市场）**
  - 推荐：卜卜贝锅物类，适合多人分享

#### 甜品
+ **黄师奶甜品店（陈村农贸市场）**
  - 亮点：本地“平靓正”经典糖水店
+ **北滘大树头甜品店（陈村农贸市场）**
  - 亮点：传统粤式甜品选择多

#### 晚餐
+ **老友记大排档夜宵店**
  - 适合：喜欢烟火气和夜宵氛围
+ **顺德陈村水蟹粥**
  - 适合：想吃偏清淡、暖胃的收尾晚餐

### <span id="parking">🅿️停车攻略</span>

+ **陈村农贸市场**
  - 有停车场，收费约 `5元/小时`
  - 适合“午餐+甜品”同区域连续打卡
+ **潭州木趣森林公园**
  - 有停车场，`前3小时免费`
+ **花卉世界停车**
  - 建议导航到 `潭村工业区`
  - `前3小时免费`

### <span id="tips">💡实用贴士</span>

+ **行程节奏**：午餐和甜品放同一片区，减少频繁停车和走回头路
+ **避堵建议**：尽量在20:00前吃完晚餐，早点上返程路
+ **点单建议**：午餐重口、晚餐清淡，体验更均衡
+ **机动安排**：若下午景点停留超时，优先保留晚餐与返程，不强行加大墩村

* 🌇 一天不赶路，吃好、逛好、拍好，再从容回东莞。
