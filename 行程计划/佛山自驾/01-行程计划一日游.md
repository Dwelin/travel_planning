### <span id="daily_plan">🗺️行程计划两条路线</span>

#### **Plan A：禅城慢享约会线（祖庙-岭南天地）**
> 适合：第一次来佛山，想边逛边吃边拍照

| 时间 | 活动内容 | 详细信息 | 备注 |
|------|---------|---------|------|
| 09:00 | 抵达禅城 | 停车到岭南天地商圈 | 建议停一天不挪车 |
| 09:20-11:00 | 早茶开局 | 点心+肠粉+粥 | 两人分食，留胃口 |
| 11:10-12:20 | 祖庙片区散步 | 老街拍照+慢逛 | 轻步行，不赶时间 |
| 12:30-14:00 | 午餐 | 烧味或顺德菜 | 点1招牌+1基础款 |
| 14:10-15:30 | 下午茶 | 双皮奶/姜撞奶 | 约会氛围时段 |
| 15:40-17:30 | 岭南天地二刷 | 小店扫街+文创 | 控制小吃量 |
| 18:00-20:00 | 晚餐收官 | 创意粤菜或顺德菜 | 饭后返程 |

#### **Plan B：顺德大良美食线（早茶-甜品-私房菜）**
> 适合：纯美食党，想把顺德味道吃透

| 时间 | 活动内容 | 详细信息 | 备注 |
|------|---------|---------|------|
| 08:45 | 抵达大良 | 停至大良商圈停车场 | 步行覆盖核心美食区 |
| 09:00-10:50 | 早茶主场 | 虾饺、凤爪、陈村粉 | 热门店先取号 |
| 11:00-12:00 | 甜品加餐 | 双皮奶、姜撞奶 | 1份分食即可 |
| 12:20-13:50 | 午餐 | 顺德私房菜 | 午市更划算 |
| 14:00-15:30 | 饭后散步 | 清晖园周边慢走 | 聊天消食 |
| 15:40-17:00 | 咖啡时段 | 安静咖啡馆休息 | 准备晚餐 |
| 17:20-19:00 | 轻晚餐 | 牛杂/煲仔饭/粥底火锅 | 19:00后返程 |

### <span id="landing">📌落地清单（店名+停车场）</span>

+ **主停车场（建议）**：
  - `岭南天地P1停车场`（导航关键词：岭南天地P1停车场）
  - `Nova岭南站停车场`（导航关键词：Nova岭南站停车场）
  - `铂顿城停车场`（导航关键词：铂顿城停车场）

+ **早茶（09:20-11:00）**：
  - `陶陶居（佛山岭南天地店）`
  - `点都德（禅城商圈门店）`
  - 备选：`稻香（禅城门店）`

+ **午餐（12:30-14:00）**：
  - `猪肉婆私房菜（佛山门店）`
  - `太艮堡毋米粥（佛山门店）`
  - 备选：`顺峰山庄（佛山门店）`

+ **下午茶（14:10-15:30）**：
  - `民信老铺（佛山门店）`
  - `仁信老铺（佛山门店）`
  - 备选：`欢姐伦教糕（佛山门店）`

+ **晚餐（18:00-20:00）**：
  - `凤城酒家（佛山门店）`
  - `炳胜品味（佛山门店）`
  - 备选：`同记鸡粥（禅城门店）`

+ **执行建议**：先到主停车场，再步行觅食；排队超45分钟直接切换同时段备选店。

#### Plan B 落地清单（顺德大良）

+ **主停车场（建议）**：
  - `清晖园停车场`（导航关键词：清晖园停车场）

  - `印象城（顺德店）停车场`（导航关键词：顺德印象城停车场）

  - `龙的酒楼（顺德门店）`
  - 备选：`点都德（顺德门店）`

+ **甜品（11:00-12:00）**：
  - `民信老铺（大良华盖路店）`
  - `仁信老铺（大良门店）`
  - 备选：`欢姐伦教糕（顺德门店）`

+ **午餐（12:20-13:50）**：
  - `猪肉婆私房菜（顺德总店）`
  - `寻味顺德（大良门店）`
  - 备选：`太艮堡毋米粥（顺德门店）`

+ **轻晚餐（17:20-19:00）**：
  - `肥光鱼生（顺德门店）`
  - `文华老友记煲仔饭（顺德门店）`
  - 备选：`牛展煲仔饭（顺德门店）`

+ **执行建议**：优先选择“可线上取号”的门店；同一商圈内解决早茶+甜品+晚餐，减少二次停车。

### <span id="tips">💡实用贴士</span>

+ **导航方法**：优先导航停车场名称，不直接导店名
+ **排队上限**：单店等待超过45分钟就切备选
+ **行程节奏**：正餐2顿+甜品1顿+咖啡1顿，舒适不赶
+ **雨天方案**：优先商场联动路线（停车、吃饭、休息一体化）
